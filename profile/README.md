### Инструменты

| Проект | Для чего |
| :--- | :--- |
| **[ESKA](https://github.com/odineska/eska)** | CLI на Rust: метаданные Designer XML, форматирование BSL и запросов, проверки для CI, Git и сборка файлов 1С. |
| **[ESKA: 1C Explorer](https://github.com/odineska/eska-vscode-explorer)** | Метаданные, свойства объектов, модули и запросы 1С в VS Code и VSCodium. Работает вместе с ESKA. |
| **[Exodus](https://github.com/odineska/exodus)** | Библиотека Result / Either для 1С: результат операции, данные и обработка ошибок. |

### С чего начать

[Установите нужные компоненты](https://odineska.github.io/eska/docs/#installation)
и подключите выгрузку Designer XML в Explorer. В
[руководстве](https://odineska.github.io/eska/docs/) есть примеры для конфигураций,
расширений, внешних обработок и отчётов, а также девять рабочих сценариев.

### Обратная связь

Ошибки и идеи — в Issues: [ESKA](https://github.com/odineska/eska/issues)
или [Explorer](https://github.com/odineska/eska-vscode-explorer/issues).
В описании укажите версии компонентов и шаги для повторения.
